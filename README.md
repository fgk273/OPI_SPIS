# ТелекомСервис — АИС оператора связи

Учебный проект по дисциплине «Основы программной инженерии» (группа 4431), вариант 31:
автоматизированная информационная система оператора связи.

> В репозитории размещены условные исходные файлы и документация.

## Назначение

Единая система вместо разрозненных таблиц: реестр абонентов и договоров, биллинг,
техническая поддержка, мониторинг сети и отчётность.

## Структура

| Путь | Назначение |
|---|---|
| `src/subscribers.py` | реестр абонентов, уникальность номера |
| `src/billing.py` | тарифы, лицевой счёт, блокировка при нулевом балансе |
| `src/support_tickets.py` | заявки технической поддержки |
| `src/network_monitor.py` | состояние сетевого оборудования |
| `src/reports.py` | заготовка отчётности |
| `tests/` | модульные тесты |
| `docs/redmine.md` | развёртывание Redmine для управления проектом |

## Запуск тестов

    python3 -m unittest discover -s tests -t .
